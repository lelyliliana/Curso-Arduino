# Unidad 19 — I2C y SPI: fundamentos

## Objetivo
Comprender por qué varios periféricos utilizan buses compartidos.

## I2C
Utiliza típicamente dos señales:
- SDA;
- SCL.

Los dispositivos suelen identificarse mediante direcciones.

## SPI
Utiliza reloj y líneas de datos, además de selección de dispositivo. Suele ofrecer mayor velocidad a cambio de más señales.

## Importante
Pinout, niveles, resistencias pull-up y compatibilidad dependen de placa y módulo. Consulta documentación.

## Reto
Compara I2C y SPI para conectar varios sensores: número de líneas, direccionamiento, velocidad y complejidad.
