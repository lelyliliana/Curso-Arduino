# Práctica — Inventario de bus I2C

## Antes
Identifica SDA/SCL de tu placa y niveles eléctricos de los módulos.

## Objetivo
Detectar direcciones antes de integrar bibliotecas.

## Registro
| dispositivo | dirección detectada | dirección esperada | tensión |
|---|---|---|---|
| | | | |

## Diagnóstico
Si no aparece:
- alimentación;
- GND;
- SDA/SCL;
- dirección;
- pull-ups;
- compatibilidad de nivel;
- módulo real.

## Reto
Conecta dos dispositivos compatibles al mismo bus y documenta cómo coexisten.
