# Checklist — Proyecto final

## Hardware
- [ ] Componentes identificados.
- [ ] Tensiones verificadas.
- [ ] Alimentación dimensionada.
- [ ] Cargas de potencia aisladas del GPIO mediante etapa adecuada.
- [ ] Conexiones documentadas.

## Software
- [ ] Código organizado.
- [ ] Pines definidos claramente.
- [ ] No depende innecesariamente de delays largos.
- [ ] Estados/eventos comprensibles.
- [ ] Datos inválidos se manejan.

## Pruebas
- [ ] Cada subsistema fue probado.
- [ ] Integración completa probada.
- [ ] Casos límite.
- [ ] Fallos previsibles.
- [ ] Reinicio/estado inicial.

## Documentación
- [ ] Lista de materiales.
- [ ] Conexiones.
- [ ] Código.
- [ ] Instrucciones.
- [ ] Limitaciones.
