# Unidad 17 — Pantallas y visualización

## Objetivo
Mostrar datos localmente sin depender del monitor serie.

Pantallas comunes pueden utilizar interfaces paralelas, I2C o SPI. Verifica el controlador exacto.

## Proceso recomendado
1. Identifica controlador.
2. Confirma voltaje.
3. Confirma interfaz.
4. Prueba un ejemplo mínimo.
5. Muestra texto fijo.
6. Integra variables del sensor.

## Diseño
No actualices toda la pantalla innecesariamente a máxima velocidad. Prioriza legibilidad y cambios útiles.

## Reto
Crea un panel que muestre dos variables de sensor y un estado del sistema.
