# Unidad 21 — Proyecto: sistema de monitoreo

## Objetivo
Integrar sensores, temporización y visualización en un sistema que observe el entorno.

## Requisitos
- al menos un sensor;
- lectura periódica no bloqueante;
- monitor serie o pantalla;
- indicador de estado;
- umbral configurable;
- manejo de lectura inválida;
- documentación del circuito.

## Fases
1. Prueba sensor aislado.
2. Registra valores.
3. Define rangos.
4. Integra visualización.
5. Añade alerta.
6. Prueba casos límite.

## Evidencias técnicas
Documenta modelo exacto de sensor, conexiones, alimentación, frecuencia de muestreo y limitaciones.

## Reto de ampliación
Registra datos en el computador o transmite a otro dispositivo.
