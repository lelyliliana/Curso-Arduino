# Unidad 13 — Temperatura y ambiente

## Objetivo
Integrar un sensor ambiental mediante una biblioteca o interfaz apropiada.

Existen muchos sensores (analógicos y digitales) con protocolos diferentes. Esta unidad enseña el proceso, no un pinout universal.

## Proceso
1. Identifica modelo exacto.
2. Consulta tensión y protocolo.
3. Instala biblioteca confiable si se necesita.
4. Ejecuta ejemplo mínimo.
5. Comprueba valores plausibles.
6. Integra al proyecto.

## Datos inválidos
Algunas bibliotecas indican fallo mediante valores especiales. El programa debe detectar lecturas inválidas.

## Reto
Registra temperatura/humedad periódicamente sin bloquear otras tareas y genera una alerta configurable.
