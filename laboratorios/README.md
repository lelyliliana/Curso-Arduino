Los ejercicios reutilizan componentes y GPIO en montajes separados. Los proyectos 21–23 integran una base concreta; amplía con pantalla, motor o comunicación después de revisar alimentación, pines y timers.

Logica.h y Trama.h contienen las funciones utilizadas por sketches y pruebas de escritorio. No simulan la placa completa. Consulta [la verificación](../docs/VERIFICACION.md) para conocer qué se comprobó.
