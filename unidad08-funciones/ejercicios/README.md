# Ejercicios — Organización del código

1. Extrae una función para leer un sensor.
2. Crea una función que convierta ADC a porcentaje.
3. Separa actualización de LED de lectura de botón.
4. Refactoriza un semáforo sin repetir digitalWrite.
5. Crea funciones para estado normal/alerta.

## Reto
Toma un sketch de más de 40 líneas y divídelo por responsabilidades. Explica por qué cada función existe.
