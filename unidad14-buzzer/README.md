# Unidad 14 — Buzzer y señales

## Objetivo
Generar señales audibles y comprender diferencias entre buzzer activo y pasivo.

Un buzzer activo puede sonar con una señal simple. Uno pasivo permite generar tonos mediante frecuencia. Verifica el componente.

## tone()
En placas compatibles, tone() puede generar una frecuencia en un pin.

```cpp
tone(8, 1000, 200);
```

## Reto
Crea patrones diferentes para estados normal, advertencia y alarma sin depender de una secuencia larga de delays.
