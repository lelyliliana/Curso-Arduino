# Checklist de banco de trabajo

Antes de energizar cualquier práctica:

- [ ] La placa está identificada.
- [ ] El cable USB es adecuado y transmite datos.
- [ ] No hay conexión directa entre alimentación y GND.
- [ ] La polaridad de componentes está comprobada.
- [ ] Los LED tienen resistencia limitadora.
- [ ] Los componentes comparten una referencia de tierra cuando el circuito lo requiere.
- [ ] Ninguna carga de potencia está conectada directamente a un GPIO.
- [ ] La tensión de cada componente es compatible.
- [ ] El circuito fue revisado con la alimentación desconectada.
- [ ] Sé qué debería ocurrir al energizar.

## Si algo se calienta
Desconecta inmediatamente y revisa el circuito. No continúes probando por ensayo y error.
