# Diagnóstico — No puedo cargar el programa

Comprueba en orden:

1. ¿El cable USB transmite datos?
2. ¿La placa aparece en el sistema?
3. ¿Seleccionaste el modelo correcto?
4. ¿Seleccionaste el puerto correcto?
5. ¿El sketch compila?
6. ¿Otra aplicación está usando el puerto?
7. ¿El mensaje de error habla de compilación o de carga?

## Diferencia importante
**Error de compilación:** el código no pudo convertirse en programa.

**Error de carga:** el programa compiló, pero no pudo transferirse a la placa.

No cambies conexiones del circuito para resolver un error puramente de compilación.
