# Checklist antes de integrar

- [ ] Todos los componentes están identificados.
- [ ] Tensiones compatibles.
- [ ] Corriente de la fuente suficiente.
- [ ] Cargas de potencia usan etapa adecuada.
- [ ] GPIO no alimentan cargas indebidas.
- [ ] GND/referencias están diseñadas.
- [ ] Pines coinciden con código.
- [ ] Cada subsistema fue probado por separado.
- [ ] Existe estrategia ante error.
- [ ] El circuito puede apagarse de forma segura.
