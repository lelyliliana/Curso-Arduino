# Unidad 20 — Diseño de prototipos y alimentación

## Propósito
Pasar de prácticas aisladas a un sistema integrado que pueda funcionar de forma confiable.

## Presupuesto de energía
Lista cada componente:
- tensión;
- consumo típico;
- consumo máximo relevante;
- fuente.

No sumes cargas a ciegas sobre el regulador o USB.

## Tierra común
Cuando dos circuitos intercambian señales y usan fuentes separadas, frecuentemente necesitan una referencia común, salvo arquitecturas con aislamiento. Analiza el caso concreto.

## Distribución
Separa conceptualmente:
- lógica;
- sensores;
- actuadores;
- potencia.

## Diseño
Antes de montar:
1. diagrama de bloques;
2. lista de componentes;
3. tabla de pines;
4. presupuesto de corriente;
5. secuencia de funcionamiento;
6. estados de error;
7. plan de pruebas.

## Reto
Diseña completamente en papel un sistema con sensor, pantalla y actuador. Incluye tabla de conexiones y alimentación antes de construir.
