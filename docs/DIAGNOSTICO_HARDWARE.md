# Diagnóstico de hardware — Método general

Cuando una práctica no funciona, evita cambiar muchas cosas a la vez.

## 1. Alimentación
- tensión correcta;
- polaridad;
- corriente disponible;
- GND.

## 2. Conexiones
- pin físico;
- continuidad;
- protoboard;
- cables.

## 3. Componente
- modelo exacto;
- pinout;
- orientación;
- hoja de datos.

## 4. Programa mínimo
Reduce el sistema a la prueba más pequeña posible.

## 5. Observabilidad
Usa Serial o medición para comprobar qué está ocurriendo.

## 6. Integración incremental
Añade un componente o función a la vez.

## Regla
Si un sistema de cinco módulos falla, no depures los cinco simultáneamente. Demuestra primero que cada subsistema funciona por separado.
