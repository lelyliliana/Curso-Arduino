# Ejercicios — Sensores analógicos
1. Registrar mínimo/máximo.
2. Promedio de N muestras.
3. Convertir a porcentaje solo si el rango representa esa interpretación.
4. Detectar umbral con histéresis conceptual.
5. Comparar lectura instantánea y filtrada.

## Reto
Caracteriza experimentalmente un sensor y documenta qué puedes afirmar de la señal y qué no.
