# Unidad 11 — Sensores analógicos

## Objetivo
Interpretar señales variables provenientes de sensores.

No conviertas automáticamente una lectura ADC en una unidad física. Para obtener unidades reales necesitas conocer la relación del sensor, referencia y calibración.

## Flujo
```text
magnitud física → sensor → voltaje → ADC → valor → interpretación
```

## Promedio simple
Varias muestras pueden reducir variaciones aleatorias, aunque también cambian la respuesta temporal.

## Reto
Registra 20 muestras de una señal, calcula promedio, mínimo y máximo y observa la diferencia entre lectura instantánea y promedio.
